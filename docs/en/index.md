# Chest Count Overlay

A **client-only Minecraft 1.21.11 · Fabric · Java 21** mod showing container item totals beside the vanilla screen.

![Actual chest overlay showing 128 torches and 96 stone](/images/cco-chest-counts.png)

Counts synchronized chest, shulker-box and bundle contents, merging by item and data components. Keeps vanilla inventory and server behavior intact. Starts collapsed; expand with the top arrow or grave-accent key.
