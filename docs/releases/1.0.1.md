# Chest Count Overlay 1.0.1

适用于 Minecraft 1.21.11 / Fabric Loader ≥0.18.0 / Java 21；需要 Fabric API 与 YACL，Mod Menu 可选。

- 保留箱类容器及潜影盒的透明数量统计栏、展开/收起、滚动与 YACL 设置。
- 统计已同步的潜影盒和收纳袋内容；按物品与完整数据组件合并，玩家背包不计入。
- 嵌套统计采用 `BigInteger` 保留精确总数，增加每次 16384 个嵌套栈的访问上限与日志，最多展开 8 层。
- 堆栈键的哈希只读取物品类型，完整数据组件相等判断仍决定是否合并，避免哈希提前递归整个嵌套图。

本版本已经发布到 GitHub；新增文档和发布工具不覆盖原有发行 JAR。完整功能与截图见[使用说明](../guide.md)。

## English

For Minecraft 1.21.11 / Fabric Loader ≥0.18.0 / Java 21. Requires Fabric API and YACL; Mod Menu is optional.

- Retains the transparent count rail for chest-like containers and shulker boxes, expansion/collapse, scrolling and YACL settings.
- Counts synchronized shulker-box and bundle contents, merging identical item/component combinations while excluding player inventory.
- Uses `BigInteger` for exact totals, limits each pass to 16384 nested stack visits with a warning, and expands at most eight nested levels.
- Uses a shallow item-only hash while complete component equality still controls merging, preventing the hash from recursively traversing a nested graph before visit limits apply.

This version already exists on GitHub. Documentation and release tooling do not replace its original JAR. Read the [user guide](../en/guide.md).
