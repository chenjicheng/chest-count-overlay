# Chest Count Overlay / 箱子数量统计

Minecraft **1.21.11 · Fabric · Java 21** 纯客户端模组，在容器旁显示物品合计数量。

![实际箱子统计效果：火把 128、石头 96](/images/cco-chest-counts.png)

读取已同步的箱子、潜影盒和收纳袋内容，按物品与数据组件合并；保留原版容器与服务器行为。默认收起，通过顶部箭头或反引号键展开。
